## 🚰 Install by tapping repository

```sh
brew tap 5ouma/tap
```

<br />

### 🧾 CLI tools

- [**⌨️ mksei**](https://gist.github.com/miclf/bf4b0cb6de9ead726197db7ed3d937b5)

  ```sh

  ```

- [**📑 mli**](https://github.com/5ouma/mli)
